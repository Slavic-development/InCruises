# INCRUISES — Ocean Edition

Многостраничный статический сайт о членстве в клубе путешествий inCruises. Работает без сборки, npm и серверной базы данных: откройте `index.html` в браузере или поднимите любой статический сервер.

## Страницы

- `index.html` — первый экран с фоновым видео, идеи отдыха с фильтрами, видео о членстве, возможности, калькулятор членских платежей, секция контактов с карточкой консультанта и формой.
- `membership.html` — четыре плана, калькулятор, сравнительная таблица, изменения Membership 3.X.
- `benefits.html` — INsider Pricing, Reward Points, каталог направлений.
- `how-it-works.html` — последовательность участия и бронирования, чек-лист перед оплатой.
- `faq.html` — вопросы с раскрывающимися ответами.
- `register.html` — шаги к регистрации и секция контактов.

## Настройки

Все контакты и пути собраны в `js/config.js`:

```js
window.SITE_CONFIG = {
  referralLink: '',   // Персональная ссылка https://...
  whatsapp: '',       // Номер с кодом страны, например 77001234567
  instagram: '',      // Логин без @ или полная ссылка
  consultantName: 'Ольга',
  videoPath: 'videos/bg.mp4',
  membershipVideos: { ru: 'videos/intro-ru-short.mp4', en: 'videos/intro-en-short.mp4' },
  videoPoster: 'images/hero.jpg'
};
```

Пустые контакты скрываются автоматически. Пока `whatsapp` пуст, форма объясняет, что отправка недоступна. Пока `referralLink` пуста, кнопки регистрации ведут на внутреннюю страницу, а не на выдуманный адрес.

`consultantName` подставляется в трёх местах: подпись под логотипом, имя и инициал в карточке консультанта, текст alt у её фотографии.

## Карточка консультанта

В секции «Начнём с разговора» (на `index.html` и `register.html`) показывается фото консультанта. Положите файл `images/avatar.jpg` — и он подставится сам, правки кода не нужны. Пока файла нет, вместо фото отображается кружок с первой буквой имени из `consultantName`.

## Языки

Сайт двуязычный (RU/EN), выбор запоминается в браузере. Тексты лежат в трёх местах:

- `js/translations.js` — основной словарь;
- `copyUpdates` в `js/main.js` — правки формулировок поверх словаря;
- атрибуты `data-ru` / `data-en` в HTML — блоки, которых нет в словаре.

## Форма заявки

Форма не отправляет данные на сервер. Она открывает WhatsApp с готовым текстом сообщения, посетитель подтверждает отправку сам. Токен бота и доступ к аккаунту не нужны.

## Калькулятор платежей

Формула: стартовая сумма + ежемесячный платёж × (число месяцев − 1); стартовый платёж считается первым месяцем. Это арифметическая иллюстрация, а не счёт клуба: баллы, стоимость круиза, сборы и налоги в расчёт не входят.

Цифры тарифов заданы в двух местах и не синхронизируются автоматически: таблица в `membership.html` и объект `plans` в `js/main.js`. При смене тарифов правьте оба.

## Видео

- `videos/bg.mp4` — фоновый ролик первого экрана: без звука, по кругу, с кнопкой паузы. Не загружается в режиме экономии трафика и при настройке уменьшенного движения — тогда виден фотофон.
- `videos/intro-ru-short.mp4` и `videos/intro-en-short.mp4` — ознакомительные ролики о членстве (5:24, 720p). Переключатель языка меняет ролик. Автозапуска и зацикливания нет.

Чтобы заменить ролики, обновите файлы под теми же именами или поменяйте `membershipVideos` в `js/config.js`.

## Публикация

Загрузите содержимое папки на статический хостинг так, чтобы `index.html` оказался в корне сайта. Для Cloudflare Pages: build command пустой, каталог вывода — корень проекта; если сайт лежит в подпапке, укажите её как root directory.

Базовые title, description, Open Graph и favicon уже добавлены. `og:image` и `canonical` намеренно не заполнены выдуманным доменом — добавьте абсолютные адреса после привязки своего домена.

## Оформление

`css/style.css` — все стили; последний раздел содержит карточку консультанта. Шрифты загружаются с Google Fonts; без интернета используются системные. Все фотографии лежат в `images/`, внешних ссылок на картинки нет.

## Заметка о размере репозитория

В истории git лежат несжатые версии видео, из-за этого папка `.git` занимает около 300 МБ. На публикацию это не влияет, но замедляет копирование и клонирование. При желании историю можно очистить отдельной операцией.
