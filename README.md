# INCRUISES — Ocean Edition

Готовый многостраничный статический сайт. Откройте index.html или запустите через VS Code Live Server. Работает без сборки, npm и серверной базы данных.

## Что поменять перед запуском

Откройте js/config.js. Всё оформление ссылок собрано в одном месте:

```js
window.SITE_CONFIG = {
  referralLink: 'https://ВАША-ПЕРСОНАЛЬНАЯ-ССЫЛКА',
  whatsapp: '77001234567',
  instagram: 'ваш_логин',
  consultantName: 'Ваше имя',
  videoPath: 'videos/bg.mp4',
  videoPoster: 'images/hero.jpg'
};
```

Пример номера замените на свой. Номер — с кодом страны. Instagram — логин без @ или HTTPS-ссылка. Реальные контактные данные и реферальная ссылка в исходном архиве отсутствовали, поэтому поля оставлены пустыми. Пустые контакты скрыты. Пустая регистрационная ссылка ведёт к консультации, а не к выдуманному адресу. До добавления WhatsApp форма объясняет, что отправка недоступна.

## Видео

Скопируйте ваше видео из предыдущей версии в videos/bg.mp4. Видео в этом архиве отсутствует, потому что оно осталось на вашем компьютере. Видео не имеет звука и панели управления, повторяется по кругу. Есть отдельная кнопка паузы. Рекомендуемый формат: MP4 H.264, 720p или 1080p, 20–60 секунд. При ошибке загрузки виден фотофон. В режиме экономии трафика и при настройке уменьшенного движения фоновое видео не загружается.

## Страницы и возможности

- index.html: первый экран, идеи отдыха с фильтрами, видео о членстве, возможности, интерактивное сравнение членских платежей и консультация.
- membership.html: четыре плана, сравнение, калькулятор платежей и условия бронирования.
- benefits.html: форматы отдыха, цены клуба и Reward Points.
- how-it-works.html: последовательность участия и бронирования.
- faq.html: вопросы с раскрывающимися ответами.
- register.html: регистрация и форма консультации.
- js/translations.js: основной словарь RU/EN. Новые формулировки находятся в copyUpdates в js/main.js, новые блоки — в data-ru/data-en внутри HTML.
- css/style.css: оформление. Последний раздел V4 задаёт новый визуальный стиль.

Форма не сохраняет данные на сервере и не отправляет их автоматически. Она открывает WhatsApp с подготовленным текстом. Посетитель подтверждает отправку в WhatsApp. Не требуется токен бота или доступ к аккаунту.

Калькулятор использует суммы из исходной версии. Формула показана рядом: стартовая сумма плюс ежемесячный платёж за оставшиеся месяцы. Это арифметическая иллюстрация с допущением, что стартовый платёж относится к первому месяцу; она не заменяет счёт клуба. Баллы и стоимость круиза в расчёт не включены. Условия и тарифы не синхронизируются автоматически. Перед коммерческим запуском подтвердите применимость этих сумм и этого допущения, при необходимости поправьте таблицу и объект plans в js/main.js.

## Запуск на хостинге

Загрузите содержимое папки incruises_new на статический хостинг. index.html должен оказаться в корне сайта. Можно использовать существующий процесс публикации через Cloudflare Pages: build command пустой, каталог вывода — корень проекта. Если проект в подпапке, выберите её как root directory.

После привязки своего домена добавьте абсолютный og:image и canonical с адресом именно своего сайта. Они намеренно не заполнены выдуманным доменом. Базовые title, description, Open Graph и favicon уже добавлены.

## Передача заказчику

Покажите главную, мобильную версию, калькулятор и путь от первого экрана до сообщения в WhatsApp. В цену работы можно включить индивидуальное оформление, подключение его контактов, размещение на хостинге, перенос контента и согласованный срок правок. Домен, платные сервисы и последующее обслуживание согласуйте отдельно. Важнее продавать понятный готовый результат, чем количество строк кода.

## Фотографии

Все фотографии сохранены внутри images: сайт не зависит от внешних ссылок на изображения. Исходные изображения Pexels из предыдущего проекта и новые фотографии Unsplash описаны в ASSETS.md. Google Fonts требует интернета; при недоступности шрифтов используются системные. Ознакомительные ролики загружаются из папки videos, без YouTube.

## V5: локальные ознакомительные видео

YouTube заменён на HTML5-плеер с кнопками воспроизведения, громкостью, перемоткой и полноэкранным режимом. Оба ролика включены в архив:

- videos/intro-ru-short.mp4 — русский, 5:24, 720p.
- videos/intro-en-short.mp4 — английский, 5:24, 720p.

Выбор RU/EN автоматически меняет ролик. При смене языка он останавливается и начинается с начала после нажатия Play. Открыть видео позволяет посмотреть выбранную версию в отдельной вкладке. Ознакомительное видео не запускается автоматически и не зацикливается. Фоновый ролик videos/bg.mp4 подключается отдельно; скопируйте его из своей папки, если ещё не добавляли.

Чтобы заменить ознакомительные ролики позже, обновите файлы под теми же именами либо измените membershipVideos в js/config.js. Файлы должны оставаться внутри папки сайта для корректной работы локального просмотра.
